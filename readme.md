# 🎲 Domino Game

## 📌 Sobre o Projeto

O **Domino Game** foi desenvolvido como um mini desafio proposto por um **Doutor e Coordenador da graduação de Análise e Desenvolvimento de Sistemas**, com o objetivo de colocar em prática conceitos de programação, lógica e modelagem de regras de negócio através de um jogo clássico.

O projeto consiste em uma versão digital do dominó executada diretamente no navegador, permitindo aplicar conhecimentos de desenvolvimento web em um cenário que exige controle de estado, validação de jogadas e organização da lógica da aplicação.

Mais do que criar um jogo, o desafio foi uma oportunidade de desenvolver habilidades fundamentais para a construção de sistemas reais, simulando problemas que um desenvolvedor encontra no dia a dia ao implementar regras e fluxos de funcionamento.

---

## 🛠️ Tecnologias Utilizadas

### 🌐 HTML

Responsável pela estrutura do jogo, organizando os elementos visíveis na tela, como peças, áreas de jogo, placares e controles.

### 🎨 CSS

Utilizado para estilização da interface, organização do layout e melhoria da experiência visual do usuário.

### ⚙️ JavaScript

Responsável por toda a lógica do projeto, incluindo:

* Controle das peças;
* Validação de jogadas;
* Atualização da interface;
* Regras do dominó;
* Interação entre jogador e sistema.

---

## 🎯 Objetivos Alcançados

Como estudante com foco em me tornar um **Desenvolvedor Full-Stack**, este projeto foi importante porque permitiu praticar habilidades que vão além da construção de páginas estáticas.

Durante o desenvolvimento foi possível trabalhar conceitos como:

* Lógica de programação;
* Estruturas condicionais e de repetição;
* Manipulação do DOM;
* Organização de código;
* Resolução de problemas;
* Modelagem de regras de negócio;
* Desenvolvimento de interfaces interativas.

Além disso, o projeto ajudou a compreender como sistemas reais funcionam internamente, já que um jogo também precisa controlar estados, validar ações do usuário e responder corretamente a diferentes situações.

Cada funcionalidade implementada contribuiu para fortalecer minha base técnica e minha capacidade de desenvolver aplicações cada vez mais completas.
